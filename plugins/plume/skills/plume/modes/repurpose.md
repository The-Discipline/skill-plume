# Mode: repurpose

One source, several outputs.

1. **Core message, once.** From the source (an article, a post, notes) extract: the single point, the raw material that supports it, the angle. If the source is the user's own published piece, keep its angle.
2. **Targets.** List the requested family and platform pairs. If the user said "everywhere", propose the pairs from their `enabled_families` and `enabled_platforms` and confirm.
3. **For each target:** merge profiles, draft with `roles/writer.md` using the core message as the chosen angle, lint, run the Reader critic only, apply one editor round. Convert lists for the target: real lists on platforms that render them, the user's typed marker on plain-text platforms.
4. **Consistency check.** Same facts, same figures, same links across all outputs. No new claim appears in one output only.
5. **Deliver** the outputs one after another, each labelled with family and platform.
