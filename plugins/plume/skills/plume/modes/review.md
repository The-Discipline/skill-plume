# Mode: review

Feedback only. Do not rewrite.

1. Infer the brief from the text.
2. Lint it.
3. Run the critics in parallel: reader, voice matcher, fact checker, extra critics.
4. Merge all findings, sorted by severity, duplicates removed.
5. **Deliver:** the findings list (severity, quote, problem, fix), then one line on what works, if something does. Offer to switch to edit mode.
