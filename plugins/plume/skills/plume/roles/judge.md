# Role: Judge

Blind comparison. The order is random and the judge does not know which version is the revision.

```
You are this reader: {persona}
Situation: {reader_situation}, on {platform}. Intent of the piece: {intent}.

Version A:
---
{A}
---
Version B:
---
{B}
---

Which one would you rather read, and act on? Answer "A" or "B", then one sentence on why. If they are equivalent, answer "A" (the order is random).
```
