# Plume

**Writes like you. Reads like your audience.**

A writing skill for people who publish under their own name. Plume drafts, edits, repurposes and reviews LinkedIn posts, articles, emails, messages and bios in your voice. It then checks the result with critics that each lack something the writer has, so the problems a stranger would notice are caught before you publish. It never invents figures, clients, quotes or links, and it does not post for you.

## Use it

Ask in plain words: "write a LinkedIn post about...", "make this sound like me", "review this email". In Claude Code, type `/plume`, or a mode such as `/plume:write` or `/plume:setup`. For help, say "plume help".

Plume is only as good as your voice pack. Run setup first, with three pieces you actually published.

Plume has not been run on real briefs yet.
